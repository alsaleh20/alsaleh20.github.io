1. Features & Mechanics
A. Advanced Dual Language System (i18n):

Full support for Arabic (RTL) and English (LTR).

Language files must be stored as PHP Arrays (lang/ar.php, lang/en.php).

Language preference saved via PHP $_SESSION and a fallback to browser default.

The entire DOM structure (dir, CSS alignments) must dynamically flip based on the active language.

B. Advanced Theme Toggle (Dark/Light Mode):

Dark Mode (Hospitality Luxury): Charcoal blacks, gold accents, and elegant typography.

Light Mode (Modern Clean): Crisp whites, soft grays, and navy blue accents.

Managed via CSS Variables (:root and [data-theme="dark"]).

Toggled via Vanilla JS and persisted in the browser's localStorage.

C. Dynamic Backend & Admin Dashboard:

A secure, password-protected admin area (hashed passwords using password_hash).

Full CRUD (Create, Read, Update, Delete) capabilities for:

Work Experience Timeline.

Skills & Core Competencies.

Gallery (Uploading images of managed restaurants/cafes).

Basic Settings (Updating phone, email, bio, and uploading a new PDF CV).

D. Frontend Layout (Single Page Application feel):

Hero Section: Profile image (image_fb1467.jpg), dynamic greeting, title, and "Download CV" button pointing to a dynamic PDF path.

About Section: Professional summary focused on food & beverage operations, upselling, and team leadership.

Skills Grid: Dynamic progress bars or tags.

Experience Timeline: Vertical chronological timeline fetched from the database.

Contact Section: Secure form (Name, Email, Subject, Message) storing messages in the DB and optionally sending an email via mail().
